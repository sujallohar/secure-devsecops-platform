DEMO 02 SECRETS

Hardcoded Secret Leakage

Attacker or developer commits unencrypted AWS Access Keys / GitHub Personal Access Tokens into git staging.

Defense: Gitleaks pre-commit shield immediately blocks commit.
DEMO 03 CONTAINER

Vulnerable Base Image Rejection

Dockerfile switches from hardened Distroless image to outdated node:14-alpine containing 34 known vulnerabilities.

Defense: Trivy scan halts pipeline; zero tainted layers reach registry.
DEMO 04 RUNTIME IDS

Container Intrusion & Privilege Escalation

Attacker gains pod shell; attempts cat /etc/shadow, modifying /etc, running package manager, and C2 external curl.

Defense: Falco eBPF alerts; readOnlyRootFS rejects write; NetworkPolicy blocks curl.
DEMO 05 ZERO TRUST

Lateral Movement & Database Bypassing

Attacker compromises Frontend tier and attempts direct lateral SQL connection to PostgreSQL database bypassing API Gateway.

Defense: Kubernetes NetworkPolicy default-deny drops TCP SYN packets (Connection timed out).
